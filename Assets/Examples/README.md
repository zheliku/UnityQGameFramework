# 示例

Package Manager 中每个编号目录都是独立 Sample。模块资源随 Sample 一起导入；移动时保留整个目录。

| Sample | 内容 |
| --- | --- |
| [00_PointPointPoint](00_PointPointPoint/README.md) | 从启动到结算的一局小游戏 |
| [01_Base](01_Base/) | 时间、日志、JSON、文件与数据转换 |
| [02_Config](02_Config/) | TOML 解析、查询与运行时配置 |
| [03_DataNode](03_DataNode/) | 路径读写、子节点与分支移除 |
| [04_Event](04_Event/) | 订阅、派发顺序与多个接收者 |
| [05_Fsm](05_Fsm/) | 状态切换、状态数据与生命周期 |
| [06_Procedure](06_Procedure/) | 流程入口、切换与传值 |
| [07_ReferencePool](07_ReferencePool/) | C# 对象复用与归还 |
| [08_ObjectPool](08_ObjectPool/) | 对象借还、工厂创建与回收策略 |
| [09_Setting](09_Setting/) | 保存和读取设置 |
| [10_Localization](10_Localization/) | 翻译、格式化与语言切换 |
| [11_DataTable](11_DataTable/) | Luban 表加载与查询 |
| [12_Resource](12_Resource/) | 资源加载、更新、缓存与释放 |
| [13_Entity](13_Entity/) | 实体显示、复用、分组与挂接 |
| [14_UI](14_UI/) | 界面打开、覆盖、缓存与分组 |
| [15_Sound](15_Sound/) | 音效、循环、分组与空间播放 |
| [16_Scene](16_Scene/) | 场景加载、切换与排序 |
| [17_FileSystem](17_FileSystem/) | 文件读写、分段与导入导出 |
| [18_WebRequest](18_WebRequest/) | GET、POST、取消与失败处理 |
| [19_Download](19_Download/) | 下载进度、续传、队列与取消 |
| [20_Network](20_Network/) | 连接、消息、心跳与失败恢复 |
| [21_Debugger](21_Debugger/) | 查看状态与注册调试窗口 |
| [22_StarForce](22_StarForce/README.md) | 多模块协作的射击游戏 |

每个场景单独运行。完整接口说明见包内 `Documentation~/Modules`。

# QGF 教程

从一个空项目开始，依次完成安装、运行示例和读取配置表。

1. [安装与第一个流程](01-getting-started.md)：Git URL 安装、目录分工、运行 StarForce、创建自己的启动流程、更新与卸载。
2. [用 Luban 制作与读取配置表](02-data-tables.md)：Excel 定义、生成、Profile、Catalog、加载、查询、扩展和目录迁移。

教程中的框架名是 UnityQGameFramework，简称 QGF。当前提供 UGF 模块及 Unity 组件的维护版本和 Luban 接入，尚未加入 QFramework 的 Architecture、Model、System 等接口。
